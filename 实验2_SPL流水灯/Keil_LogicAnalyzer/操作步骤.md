# Keil Logic Analyzer 操作

1. 双击根目录中的 `实验2_SPL流水灯.uvprojx`，先执行 **Project → Rebuild all target files**。
2. 打开 **Options for Target → Debug**，选中 **Use Simulator**，确认晶振频率为 `8.000 MHz`。
3. 按 `Ctrl+F5` 进入软件仿真。
4. 打开 **View → Analysis Windows → Logic Analyzer**。
5. 在 Command 窗口输入 `DIR VTREG`，确认当前 STM32F103C8 仿真模型列出了 `PORTA`。然后在 Logic Analyzer 的 Setup 中依次加入 `PORTA.8`、`PORTA.9`、`PORTA.10`，这是仿真 GPIO 引脚位，不是软件自记的状态变量。
6. Display Type 均选 Bit，按 `F5` 运行。时间轴上相邻换灯间隔就是单步延时，同一信号相邻两次上升沿之间是三灯完整周期。若当前仿真模型不接受 `PORTA.n`，可改看 `g_logic_pa8`、`g_logic_pa9`、`g_logic_pa10` 辅助排查程序流程；这些变量只表示代码记录的预期状态，不能当作 GPIO 引脚波形的实测结果。
7. PA8、PA9、PA10 高电平分别表示对应外接灯亮。
